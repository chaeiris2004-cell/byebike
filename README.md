# 바이바이크 운영 대시보드

## 실행

1. `.env`에 `bike_api`를 설정합니다. 현재 서버는 서울 열린데이터광장 URL 형식과 인증키 단독 형식을 모두 지원합니다.
2. PowerShell에서 `python .\server.py`를 실행합니다.
3. `http://127.0.0.1:5500`을 엽니다.

카카오 디벨로퍼스의 JavaScript SDK 허용 도메인에 `http://127.0.0.1:5500`을 등록해야 합니다. 공개 배포 시에는 배포 도메인도 등록합니다. 카카오 JavaScript 키는 브라우저에서 보이는 키이며, 서울 API 인증값은 서버에서만 사용합니다.

## 설정

`dashboard-config.js`에서 API 경로, 새로고침 주기, 페이지 크기, 지도 줌 경계와 임시 위험 기준을 조정합니다. 기본 기준은 재고율 20% 이하 부족, 90% 이상 과잉, 목표 재고율 50%입니다. 모델 담당자와 합의 후 변경해야 합니다.

## 데이터 / 예측

화면은 `{ baseTime, stations[] }` 데이터 계약을 사용합니다. 현재 재고는 서울시 실시간 API 값이며, `stock.h1`과 `stock.h3`가 아직 전달되지 않아 기본 데모에서는 결정적 시뮬레이션 값을 사용합니다. 상단의 `데모 예측` 표시가 켜진 동안 예측값은 실제 모델 결과가 아닙니다.

실제 예측 JSON을 연결할 때는 `/api/stations` 응답 어댑터만 `dashboard.js`의 `toDashboardData`에 맞춰 변경하면 됩니다. `stock.h1/h3` 값이 없고 `demoForecasts`가 꺼져 있으면 표에 `예측 없음`으로 표시됩니다.
